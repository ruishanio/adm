Before you dive in.

Questions or ideas?
Which devices can I connect?

Android phones, tablets, and emulators with authorized ADB access can connect over USB or a network. If an IP connection and wireless discovery reach the same device, ADM lists it once. Right-click to disconnect. Wireless pairing requires Android 11 or later and uses a separate pairing port.

How does screen mirroring work?

Mirror, control, and record video without audio. The desktop needs WebCodecs. If the system encoder fails on an x86_64 device running Android 6.0 or later, ADM automatically switches to a compatibility encoder. Protected content stays hidden.

Which languages does the app support?

ADM supports English, Simplified Chinese, Traditional Chinese, Japanese, French, German, Spanish, and Russian.

Can I contribute?

Yes. ADM's own code is MIT-licensed and built with Tauri, Vue, TypeScript, and Rust. Bug reports, translations, and code contributions are welcome on GitHub.
