A FEW GOOD THINGS TO KNOW

Before you dive in.

Questions or ideas?
Which devices can I connect?

Android phones, tablets, and emulators with authorized ADB access. Connect over USB or a network. Wireless debugging pairing requires Android 11 or later; pairing and connection use different ports.

Does screen mirroring include audio?

Not yet. Mirroring and recording currently capture video only. They require a working H.264 encoder and WebCodecs support. Some older emulators and protected screens cannot be captured.

Which languages does the app support?

The desktop app supports English and Simplified Chinese. This website and the README are available in eight languages.

Can I contribute?

Yes. ADM's own code is MIT-licensed and built with Tauri, Vue, TypeScript, and Rust. Bug reports, translations, and code contributions are welcome on GitHub.
