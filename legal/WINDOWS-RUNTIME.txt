Windows runtime notice / Windows 运行时说明

ADM 的自有代码按 MIT 许可提供；Microsoft Edge WebView2 Runtime 是独立的
第三方软件，适用微软的许可条款，不因 ADM 的 MIT 许可而被重新授权。
Windows 版本通过 WebView2 显示界面。缺少运行时时，安装程序从微软下载
Evergreen Bootstrapper；运行时可自动更新。

本软件使用的 WebView2 包含 Microsoft Defender SmartScreen，默认启用。
SmartScreen 会收集用户的信息并发送给微软，具体见微软隐私声明和
Microsoft Edge 隐私白皮书。WebView2 也可能向微软发送诊断数据。
这些行为由微软运行时及系统策略控制，不表示 ADM 将 Android 设备文件
上传给微软。ADM 未关闭 SmartScreen 安全保护。

disable SmartScreen.
