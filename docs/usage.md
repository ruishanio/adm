# 使用指南

[返回 README](../README.md)

## 连接设备

### USB 调试

1. 在 Android 设备的开发者选项中开启 **USB 调试**。
2. 使用支持数据传输的 USB 线连接电脑，解锁设备并确认调试授权。
3. ADM 会自动刷新设备列表；也可以点击设备列表标题旁的刷新按钮。

如果没有出现设备，先检查数据线与设备上的授权提示。Windows 部分设备还需要安装厂商提供的 USB 驱动。

### Android 11+ 无线调试

电脑与设备需处于可以互相访问的网络中。

1. 在 Android 开发者选项中开启「无线调试」，进入「使用配对码配对设备」。
2. 在 ADM 点击「连接设备」，切换到无线配对，填写设备显示的配对地址与配对码。
3. 配对成功后，使用无线调试主页面显示的 **IP 地址和连接端口** 建立连接。

配对端口与连接端口通常不同，设备关闭或重新开启无线调试后，端口也可能变化。ADM 不保存配对码。

### 已开启 TCP 调试的设备

在「连接设备」中填写 `IP:端口`。设备必须已经开启可访问的 ADB TCP 服务，填写地址本身不会为设备开启调试。

## 管理设备列表

设备列表约每 5 秒自动刷新，区分已连接与其他设备。点击条目切换当前目标；文件、安装及所有者操作均针对选中的设备执行。

右键设备可以备注名称、复制标识或从列表移除。备注只保存在本机，不修改 Android 系统名称；移除仅隐藏列表条目，可以在设置中恢复。

拖动侧栏与工作区之间的分隔区域可调整宽度。设备信息页顶部概览显示内存、数据分区、电量和运行时长，下方显示基本信息；其他参数按分组展开，设备所有者位于最下面并默认折叠，支持键盘 Enter / Space 切换：

- **基本信息**：品牌、制造商、型号、设备代号、Android / API 版本、安全补丁、序列号与产品名称。
- **硬件与存储**：展开查看 CPU 架构、芯片 / 硬件、逻辑核心数、内核版本、运行内存、数据分区容量、屏幕分辨率与显示密度。内存和数据分区显示可用量与总量，单位为 MiB / GiB；数据分区容量不等于设备标称闪存容量。
- **运行状态**：展开查看电量、充电状态、温度、健康、电压、供电来源、精确到分钟的运行时长与 IPv4 地址。
- **系统构建详情**：展开查看构建标识、版本、类型、硬件平台、Bootloader、基带、验证启动状态、加密状态和完整构建指纹。

点击「刷新信息」或使用刷新快捷键更新采样；运行数据不会持续实时刷新。设备未提供或无权限读取的信息显示为「—」。屏幕设置有覆盖值时，同时显示当前值和原始值；显示密度是系统逻辑 dpi，不代表面板物理 PPI。

## 性能监控

选择在线设备，进入「设备信息」后面的「性能监控」。设备与应用分组显示，左侧为指标及当前值，右侧为曲线；每组末尾共用时间刻度。点击 CPU 下方的核心数量可展开各核心图表，指标口径集中在底部「指标说明」。默认每 2 秒采样，可切换为 1 秒或 5 秒；曲线保留最近 2 分钟。采样串行执行，设备响应慢时会延长实际间隔，不堆积请求。暂停会停止读取，继续时重新建立速率基线；切换设备或离开页签结束会话。

- **CPU**：总占用、各核心占用及当前频率。占用由两次 `/proc/stat` 累计值求差，频率从设备 cpufreq 节点读取；核心下线或权限不足时显示「—」。不要求 root，也不修改频率策略。
- **内存**：使用量按 `MemTotal − MemAvailable` 计算，同时显示使用比例和可读取的 Swap 使用量；不把文件缓存全部视为不可用。字段含义参见 [Linux proc 文档](https://www.kernel.org/doc/html/latest/filesystems/proc.html)。
- **网络**：选择网卡查看接收、发送速率，按字节计数差值与设备时间计算。网卡分别展示，不叠加 VPN / 隧道与物理接口；此处是设备网卡吞吐，不是所选应用的流量。
- **运行与温度**：顶部显示运行时间、电量和电池温度；系统提供非正常温控状态时显示提示。电池温度不代表 CPU 温度，温控状态是否可读取决于系统实现。
- **应用性能**：按应用名称或包名检索，选择应用后读取 PSS 内存，以及相邻快照新增 HWUI 渲染帧的 FPS 和卡顿比例。PSS 按进程汇总并分摊共享内存，不能仅凭单次读数判定泄漏。FPS 是采样窗口内应用渲染帧数除以时间，不是屏幕刷新率；静止画面可能为 0，无新帧时卡顿比例显示「—」。游戏、视频、自定义渲染及厂商限制可能不提供这些统计。统计口径参见 [Android dumpsys 文档](https://developer.android.com/tools/dumpsys)。

首轮采样、计数重置、应用进程或窗口变化时不推测速率；设备不支持或尚未取得的数据使用「—」，曲线保留断点。应用未运行时不会自动启动应用，采样不会清空系统的 gfxinfo 历史。GPU 占用、功耗和磁盘吞吐尚未纳入此页。

## 已安装应用

进入「应用管理」查看主用户（用户 0）的应用。默认仅显示用户应用，可勾选「显示系统应用」；列表以应用名称为主、包名为辅；名称按设备语言读取，无法读取时保留包名。搜索支持名称和包名，不区分大小写。点击应用或信息按钮，查看版本、最低和目标 Android API、UID、安装时间、安装来源及 APK 路径；设备未提供的字段显示「—」。

在应用信息中点击「卸载应用」，核对目标设备和包名后确认。卸载会删除主用户下的应用及其数据；系统应用仅支持查看。执行前会重新核对设备传输会话和应用版本，完成后回读主用户的应用列表。设备所有者或管理策略可能阻止卸载，此时保留原始失败原因，不自动移除管理者或绕过策略。

拖动表头分隔线可调整名称、类型和状态的列宽，双击或按 Home 恢复该列默认宽度；聚焦分隔线后也可用左右方向键调整。列宽保存在本机，信息按钮保持固定宽度。列表过宽时可横向滚动，表头与内容同步；纵向滚动条从表头下方开始。

使用「刷新应用」或在此页按 `⌘/Ctrl+R` 更新列表。点击右上角「安装应用」、选择或拖入 APK 会打开安装弹窗；安装成功后自动关闭弹窗并刷新列表，失败时保留安装包及错误，可修改选项后重试。

命令行为参考 [Android 官方 ADB 文档](https://developer.android.com/tools/adb#pm)：列表和卸载均显式指定 `--user 0`，卸载还绑定确认时的版本代码。

## 安装 APK

1. 选中已连接的设备，在「应用管理」点击「安装应用」打开弹窗。直接拖入 APK 或使用选择 APK 快捷键也会打开该弹窗。
2. 拖入 APK 或使用文件选择器，核对包名、版本、最低 Android 版本等信息。
3. 按需允许 `testOnly` 测试包，然后执行安装。ADM 会覆盖安装到主用户（用户 0），完成后读取包路径和版本进行确认。

支持单个完整 APK，暂不支持 AAB、APKS 或拆分 APK。覆盖安装能否成功仍取决于签名、版本及设备限制。

如果 APK 声明了设备管理组件，ADM 会解析并提供给设备所有者配置使用；声明组件本身不会自动授予所有者权限。

## 配置设备所有者

1. 先安装包含有效设备管理组件的应用。
2. 展开「设备信息」底部的「设备所有者」，查看当前状态，选择识别到的组件，或填写 `包名/接收器类名`。
3. 点击检查条件，查看应用安装状态、现有所有者、用户和账号等结果。
4. 核对目标设备和组件，勾选授权后执行。ADM 会在执行前再次检查，并在命令完成后回读所有者状态。

当前流程仅支持单一主用户（用户 0）。是否能设置还受 Android 版本、厂商实现及设备初始化状态影响，以检查结果和设备返回信息为准。ADM 不会移除账号、工作资料或已有所有者，也不会自动恢复出厂设置。

## 文件管理

默认打开 `/sdcard`。双击文件夹进入，使用路径栏、上一级或根目录按钮导航。能访问的范围由设备的 ADB 权限决定。

名称、大小和修改时间均可通过表头分隔线调整列宽，操作方式与应用列表相同，偏好分别保存。表头固定在列表上方，纵向滚动条不占据表头，横向滚动保持列对齐。

| 操作       | 行为                                                           |
| ---------- | -------------------------------------------------------------- |
| 上传文件   | 可一次选择多个文件，上传到当前目录。                           |
| 上传文件夹 | 可选择多个文件夹，保留目录层级、隐藏文件与空目录。             |
| 下载文件   | 下载选中的普通文件，通过系统保存对话框选择位置并确认是否覆盖。 |
| 新建文件夹 | 在当前目录创建文件夹。                                         |
| 重命名     | 右键普通文件或文件夹，输入新名称。                             |
| 删除       | 右键普通文件或文件夹并确认；删除文件夹会包含其内容。           |

上传遇到同名项会拒绝覆盖或合并，符号链接和特殊文件不支持上传。批量任务中已经完成的项目不会因后续失败或取消而回滚，请刷新目录核对结果。

下载目前只支持普通单文件，不支持整个目录。下载通过临时文件完成后再替换目标；失败或取消时保留原有本地文件。删除操作不经过回收站。

## 设备日志

选择已连接的设备，进入「文件管理」后面的「设备日志」。页面自动读取 `main`、`system` 和 `crash` 缓冲区，先显示最近约 500 行，再持续接收新日志；不会清空设备日志。读取格式与缓冲区含义参见 [Android Logcat 文档](https://developer.android.com/tools/logcat)。

- **应用**：展开下拉菜单后可按应用名称或包名检索，不区分大小写；支持方向键定位、Enter 选择和 Esc 取消。选择主用户（用户 0）的应用后，以 UID 匹配日志，因此常规多进程和应用重启后仍有效。共享 UID 的其他应用也可能出现；系统组件代应用输出的日志、隔离进程或缺少 UID 的记录不保证归属于该应用。需要完整崩溃上下文时选择「全部应用」。刷新按钮重新读取应用列表。
- **级别**：选择最低级别，例如「Warn 及以上」包含 Warn、Error 和 Fatal；关键词按整行原文匹配，不区分大小写。三项条件可组合使用。
- **崩溃**：Fatal、AndroidRuntime 错误堆栈以及明确的 Java / native 崩溃和 ANR 提示会高亮，可勾选「仅崩溃」。这是日志特征标记，不是独立的崩溃检测器；不将所有 Error 都判定为崩溃。点击行可查看并复制完整原文。
- **列宽**：拖动表头右侧分隔线调整列宽；列宽不足时可向右扩展，超出窗口后横向滚动，表头与内容保持对齐；纵向滚动条仅位于表头下方的日志区域。双击分隔线或按 Home 恢复该列默认宽度，聚焦分隔线后可用左右方向键调整；列宽会保存在本机。长日志也可点击打开原文详情。
- **暂停滚动**：固定当前可见记录，后台继续接收，按钮切换为「继续滚动」；点击「继续滚动」跳到最新位置。向上滚动同样会暂停跟随。
- **导出日志**：通过系统保存对话框保存 UTF-8 `.log` 或 `.txt` 文件。导出的是点击时、当前筛选下已缓存的记录，也包括暂停滚动期间收到的内容；不是无限期录制设备的全部历史。

每个会话最多缓存 10,000 行或 8 MiB 原文，超出后淘汰最旧记录并显示数量；单行超过 16 KiB 会截断并标明。离开页签、切换设备或退出应用会停止旧客户端并释放缓存。断线或读取失败时显示错误，可重新读取；不会重启 ADB 服务，也不阻塞安装或文件操作。

## 常见问题

### 设备显示未授权或离线

解锁 Android 并检查 USB 调试授权提示；尝试重新连接数据线或刷新列表。网络设备需要确认调试仍已开启、地址与端口没有变化，且电脑可以访问设备。

### 配对成功，为什么还连不上？

配对只建立信任关系。请回到设备的无线调试主页面，使用连接地址，避免继续使用配对页面的端口。

### 是否需要自己安装 ADB？

发布包已包含 ADB。开发环境会查找 Android SDK、`ANDROID_SDK_ROOT` / `ANDROID_HOME` 和 PATH，也可以在设置中选择 ADB 路径。首次构建的资源准备方式见 [开发指南](development.md#准备环境)。

### 点击「停止等待」后，设备操作是否取消了？

该按钮终止本次 ADB 客户端等待。设备端已经提交的安装或所有者操作可能继续执行，请刷新并核对实际状态，不要仅凭停止等待判断设备操作已撤销。

### 如何切换语言？

在「设置 → 通用」选择简体中文或 English，切换立即生效。首次启动根据系统首选语言选择并保存，没有对应翻译时使用英语；ADB 与部分后端返回信息可能保留原文。

### Windows 便携版打不开怎么办？

便携版依赖系统 WebView2。可以改用安装 EXE，由安装器在缺少 WebView2 时联网下载。仅支持 Windows x64。

仍有问题时，请在 [Issues](https://github.com/ruishanio/adm/issues) 提供版本、系统、连接方式、复现步骤和必要日志。
