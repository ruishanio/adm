# 许可材料与查看入口验证

日期：2026-11-01。版本：0.1.0。修改保留在本地，未提交、推送或上传安装包。

## 实现范围

- ADM 自有代码 MIT；对外说明使用 `Device manager for Android`，保留 ADM 名称、应用标识和原数据目录。
- 设置 → 第三方许可：仅显示 Android 图形署名和 Windows 专用运行时通知；“查看完整声明”通过系统文本应用离线打开随包原文。无依赖列表、搜索、分类或逐项展开。许可与关于为并列菜单，没有嵌套入口或返回按钮。
- 359 项声明，覆盖前端依赖、复制的 shadcn-vue 组件、Tailwind、Rust 依赖及标准库、ADB 原始 NOTICE、WebView2 SDK/Runtime 与 Android 图形署名。清单保守包含构建依赖，不表示全部代码都进入二进制。
- 随包携带五份 MPL 精确源码归档，SHA-256 与 Cargo.lock 一致，可正常解压读取。
- Windows 专用配置增加安装器许可页，附 ADM MIT 和独立的 WebView2 Runtime 条款、隐私/SmartScreen 通知；macOS 不继承该协议页。
- 依赖、features、工具链、声明、源码或打包配置变化时需要重新生成和审阅快照。实际 Vite 产物的组件也须在清单中。
- `licenses:release-check` 在公开上传前要求关闭 `legal/release-review.json` 中的待办。
