# UI / UX 约束落地验证

日期：2026-11-01。宿主：macOS ARM64。

## 当前设计

- 用户要求多种颜色的小面积点缀，已撤下陶土色主题；白色工作区、浅灰侧栏、深灰正文，普通控件保持中性。
- 设备与系统信息图标蓝色、安装包紫色、文件夹琥珀色、设备所有者青绿色；应用标识浅薄荷底。在线设备与文件夹带浅色填充，离线设备为灰色。
- 图标功能色共用语义变量，主操作与焦点统一蓝色；标签文字保持中性，选中背景与文字加粗共同指示选中状态。
- 保留已移除的独立标题栏布局：macOS 三色按钮在侧栏顶部，Windows 原生按钮融入右侧工作区，设备摘要避让覆盖区域。
- 本轮仅修改样式、图标类名及安装包标题图标，未修改 ADB、安装、设备所有者或文件管理业务。
