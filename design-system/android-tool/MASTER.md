# ADM 桌面设计约束

## 产品边界

Tauri 2 / Vue 3 / TypeScript / shadcn-vue / Tailwind CSS 4，面向 macOS 和 Windows 的 Android 运维工具。以设备选择、信息查看、安装和文件操作为主。保留浅色双区和设备图标；不采用网页首页的 Hero、营销卡片或移动端底栏。

## 技能依据与取舍

设计阶段使用的 UI UX Pro Max 位于本机 `.agents/skills/ui-ux-pro-max/`，仅作可选辅助工具，不随仓库提交；以下规则是项目保留的设计依据。上游来源为 https://github.com/nextlevelbuilder/ui-ux-pro-max-skill，采用版本为 `bf41cbc3ce63e30c922e58ef48741ba6133f9aa9`。

- 已运行 `developer tool desktop utility --design-system --density 8 --variance 2`。Minimalism 的简洁层级符合目标；生成的 FAQ 落地页、深色绿色配色和外部字体不符合已确认需求，未照搬或作为默认规则保存。
- 收窄检索 `Fluent 2 desktop utility --domain style -n 1`，命中 `fluent-2`：采用语义变量、低干扰层级、统一控件状态和平台适配原则；本项目为自定义桌面视觉，不宣称实现完整 Fluent 2。
- `secondary text contrast --domain ux` 命中 Contrast Readability / Color Contrast；正常文字至少 4.5:1。
- `form progressive disclosure --domain ux` 实际命中 Submit Feedback / Form Labels，只采纳标签和反馈规则；渐进展开来自技能 quick-reference 的 Forms 条目，不伪称检索命中。
- Vue 使用组合式共享状态；标签页、复选框、对话框和右键菜单以 shadcn-vue / Reka UI 作为可访问交互基础，仍遵循本项目桌面尺寸与语义配色。

## 视觉与尺寸

用户明确要求增加多种颜色的小面积点缀，不使用统一红色或陶土色主题。工作区保持白色、侧栏浅灰、正文深灰；大面积底色和标签文字不随功能染色。保留桌面工具密度，避免整页染色、渐变、发光、磨砂、插画和浮起的设备卡片。

功能色固定用于图标：设备和信息蓝色、安装包紫色、文件夹琥珀色、设备所有者青绿色。文件夹和在线设备图标可带浅色填充。常规按钮保持中性，主操作及键盘焦点统一蓝色，成功/错误继续使用状态色。图标、文字和选中背景共同表达含义，禁止按设备序号随机分配颜色。

局部检索 `color meaning consistency --domain ux` 命中 Color Only / Color Contrast；采用颜色之外保留文字和图标、检查对比度的规则。上述功能配色为本项目设计取舍，不宣称是技能自动生成的配色方案。

系统字体：macOS 系统字体 / Windows Segoe UI / 中文系统回退；不下载字体。正文和表单 13px，辅助文字 12px，工作区设备名 16px。间距按 4/8/12/16/24px 组合；普通控件 macOS 28px、Windows 32px，图标按钮至少 28px。此处是鼠标/键盘桌面工具，不套用手机 44/48pt 触控规则。

统一变量放在 `src/renderer/styles.css`：foreground、muted、surface、sidebar、line、control-border、accent、selection、brand、device、install、folder、owner、success、error、focus、radius、spacing、motion。正常文字对比度 >=4.5:1；用于识别控件的边界和焦点 >=3:1。淡分隔线仅作分组，不承担控件边界。

Lucide 线性图标：控件 16px、设备 24px、页头 28px，统一 1.5px 笔画。设备图标与名称及副标题组成的两行内容整体居中，副标题从相同文字列起始。图标不是按钮时隐藏辅助语义；只有图标的按钮必须有可访问名称。

## 页面与交互

- 辅助信息优先用间距、换行与主次文字建立层次，不使用圆点串联，不批量替换为竖线。安装与应用详情的目标信息、APK 信息、日志 UID / PID / TID、关于页许可信息复用 `metadata-inline`。Android 版本以括号补充 API，网卡名称与地址用冒号关联；用于表示连接和运行状态的小圆点保留。
- 标签页下方的工具栏以文件管理为共同基准，共用 `workspace-toolbar`：上 / 左右 / 下内边距为 10 / 20 / 8px，第二行间隔 6px。搜索、下拉与路径导航采用 sidebar 浅灰底、透明边框和 12px 文字，高度 macOS 30px / Windows 32px；悬停轻微加深，编辑焦点与键盘焦点保留。操作为 12px 中性图标文字按钮，数量靠右，不采用独立页面的大标题或醒目实心按钮；实心主按钮用于确认弹窗。性能页内容较少，保持单行。此样式用于工作区工具栏及性能页应用选择器，不改变弹窗表单、复选框状态或图表内行内选择器。
- 左侧标题使用“设备”，右侧放置刷新按钮；应用名称统一为 ADM，全称 Device manager for Android 仅在设置说明和文档中提供，不设中文名。顶部预留 32px 无文字拖动区域，双击在当前桌面可用区域铺满与普通窗口之间切换，不进入 macOS 独立全屏。macOS 普通铺满仍保留顶部留白，仅系统全屏时收起，侧栏标题保持原来的左对齐位置；Windows 始终保留顶部区域及右上窗口按钮。侧栏标题与设备摘要也可拖动窗口，列表和标签正常点击。
- “已连接”分组右侧仅显示在线数量；刷新按钮始终位于侧栏标题右侧，零在线设备时仍可用。
- 侧栏标题 18px，设备行 52px，仅使用淡蓝灰选中底，不加竖向色标或状态圆点；显示名称、传输标识与图标；副标题使用 12px 连接方式图标与设备标识，间距 6px，不使用带底色标签；非在线设备额外显示离线 / 等待授权等文字状态；标识过长时省略，悬浮及无障碍名称保留完整标识、连接方式及状态；分组标题和设备详情提供文字状态。离线设备图标及设备名称使用中性灰。右键备注/隐藏保留，不设置 F2。连接设备采用居中的图标文字按钮，白色表面、细边框及轻微阴影，避免厚重外框。
- 侧栏最小 220px，工作区最小 640px；分隔位置保留鼠标拖动和键盘替代；布局仅占 1px，命中宽度 13px；默认显示浅色细线，鼠标悬停和拖动时仅加深中间细线，不显示蓝框。键盘调整时仅将中间细线变蓝，不给命中区添加外框，不添加凹槽或额外缝隙。
- 顶部显示当前设备与连接摘要，16px 设备名称下集中排列连接状态、连接方式、Android 版本和设备标识；以小图标加文字建立分组，不使用带底色标签或将状态单独推到最右侧。长名称省略并提供完整提示，摘要按字段换行、长标识可折行，不因窄窗口隐藏信息；标签页有图标、文字及明确选中样式，不加大幅装饰区。
- 主标签为“设备信息 / 性能监控 / 应用管理 / 文件管理 / 设备日志”。应用管理直接展示已安装应用，工具栏第二行的“安装应用”打开安装弹窗，不再设置二级标签。选择或拖入 APK 同样打开该弹窗；弹窗保留安装选项和明确的目标设备，成功后关闭并刷新列表，失败保留内容与错误。安装后配置所有者时关闭弹窗并转到设备信息，仍需单独检查及授权。
- 性能监控沿用浅色工作区，设备性能与应用性能分组，以固定宽度的左侧指标、当前数值及辅助信息对应右侧曲线，不使用仪表盘卡片。各组仅在最后一条曲线下显示时间轴；时间轴固定行高并预留最小高度，采样更新文字时不得收缩滚动范围或改变用户滚动位置；弱化网格和外框，核心小图不重复显示 100% 刻度。CPU 核心明细默认收起，通过带展开状态的“核心数”按钮查看，展开保留已采集历史；核心名与占用同排，频率位于图下。顶部固定运行时间、电量、电池温度、采样间隔和暂停操作，应用选择支持名称及包名检索，触发框与顶部采样间隔共用浅灰无可见边框样式、12px 字体和平台高度，悬停与展开状态一致。外层容器不保留滚动条空间，仅内部曲线区滚动，滚动条贴右侧，内容右边距为 12px；网卡采用标题旁的行内文字下拉入口，常态、悬停及展开均透明无框，悬停 / 展开只改变文字与箭头颜色，不添加重复名称的原生悬浮提示；保留键盘焦点及菜单内完整选项。未选应用时仅显示简短选择提示；选中后在应用指标下提供可键盘展开的“指标说明”，分别解释 FPS、卡顿比例和 PSS，不重复图表时间范围或缺值符号说明。实际错误与不支持状态仍就近显示。曲线保留最近两分钟，复用现有功能色；缺值用「—」，保留采样空档，不补零。HWUI 口径说明必须可达，不承诺游戏、视频或显示面板帧率。暂停、切换设备或离开页签停止采样，恢复时重新建立差值基线。
- 设备日志沿用浅色工作区，图标使用既有 brand 色。工具栏保持紧凑两行：首行依次为应用选择及相邻刷新、最低级别、关键词和末端的“仅崩溃”筛选；次行右侧使用轻量的暂停滚动、导出按钮；不常驻显示接收状态、日志总数或暂停后的新增计数，暂停状态直接由按钮表达，仅在读取失败、缓存淘汰或内容截断时提供必要提示。应用选择限制宽度，展开后在固定搜索区按名称或包名检索；候选项分两行显示名称、包名，列表独立滚动，取消检索不修改已选应用，重新打开恢复完整列表。关键词使用剩余空间，字段名称保留无障碍关联，不另加一排重复标签；级别使用“Debug 及以上 / Info 及以上 / Warn 及以上 / Error 及以上 / Fatal”，英文使用“or higher”，不用含义不明确的加号；下方等宽日志行铺满工作区并独立滚动，只渲染视口附近的行。表头右侧细分隔线支持拖动调整列宽，设最小宽度并记住本机偏好；双击或 Home 恢复该列默认值，左右键提供键盘替代。表头独立固定在正文上方，纵向滚动条从表头下方开始；表头与正文同步横向滚动，并按正文滚动条宽度补偿表头可用宽度；鼠标调整不显示蓝框，键盘焦点仅强调分隔线。暂停滚动仍持续接收日志；崩溃仅用红色高亮，不在原文前插入图标或“崩溃”文字，辅助技术仍可识别崩溃行，完整原文可打开详情阅读及复制。切换设备或离开页签停止该会话，不清空设备日志，不占用其他设备操作的任务锁。
- 已安装应用为紧凑的单行表格，列为应用名称、版本、安装包大小、运行状态和操作。名称前显示实际应用图标，图标不可读时使用通用图标；名称缺失直接显示包名，不再附加“名称不可用”或常驻第二行。完整包名可在提示、详情及复制操作中获取，搜索匹配名称与包名。类型和启用状态留在详情，禁用应用仅在名称旁简短标注。整行支持单击选中、双击或 Enter 查看详情、方向键切换；选中背景覆盖所有单元格。操作列保留左对齐的轻量“详情”和“⋯”，文字起点与表头对齐，右键提供相同菜单，菜单底部不附说明文字；系统应用只读，设备所有者不支持停止、清除和卸载，危险操作先核对具体目标再确认。运行状态约每 5 秒读取关联进程，包含缓存进程，未知显示「—」，不因状态变化跳动排序。安装包大小明确为 base 与 split APK 合计，不含数据或缓存。
- 应用表头、行背景及分隔线铺满工作区，滚动条靠右；上方固定工具区保留 20px 水平边距；首行是填满可用空间的搜索、刷新和末端的“显示系统应用”筛选，次行是轻量“安装应用”，数量靠右。不重复显示“已安装应用”标题，不添加统计说明行。图标按可见行读取，运行状态在页面可见时刷新；切换设备或断线清除旧列表和确认状态。
- 信息页采用一致标签列和数据列；长序列号、组件名称允许换行，必要的完整信息不能只靠鼠标悬停。
- 设备信息正文左右内边距均为 20px，未溢出时不额外预留滚动条位置；展开内容后按需滚动。默认呈现一行内存、数据分区、电量和运行时长概览，下方为无逐行边框的基本信息。硬件与存储、运行状态、系统构建详情使用整行可点击的原生折叠分组，默认收起，分组间使用淡分隔线；不做独立指标卡片或大号数字。展开保留全部字段，完整构建指纹占整行。中英文标签列分别适配，缺失读数使用「—」，合法零值保留；页面不附加缺失值和刷新机制的说明句。运行数据为手动刷新的快照，不展示未经采样的实时状态。
- 设备所有者位于信息页最下面，整组默认折叠，标题与其他折叠分组保持一致。展开后呈现当前状态和配置表单；选择管理组件后保留检查、明确授权和设置三步。安装后配置流程必须自动展开，不隐藏当前失败反馈。
- 安装弹窗宽 560px，最大高度受窗口约束，包信息与选项在内部滚动，标题和底部操作固定。拖放区适度留白，选择文件和拖放等价；进度、错误和停止等待入口在弹窗内可见。文件页采用浅色背景的可点击路径导航与直接编辑入口，编辑状态仅使用单层细焦点边框；紧凑工具栏依次为新建文件夹、上传、下载。上传菜单支持文件和文件夹，列表右键提供打开、下载、重命名和确认删除；设备标题、标签、工具栏和表头固定，只滚动文件列表，不在底部堆放操作说明。
- 设置采用 660×430px 固定双栏，不可拖动，不保留底部“完成”栏或右侧重复分类标题；语言采用标签与控件横向排列、紧凑浅色表面下拉菜单，不附加即时生效说明。连接对话框三种方式使用一体式浅灰分段控件，选中项为白色表面、细边框和轻微阴影；切换时保持 380px 高度，长内容仅在内部滚动。文件表格铺满工作区宽度，外侧无左右留白；文件与应用列表的滚动区域延伸至窗口底部，最后一项后保留随内容滚动的 12px 间距，不设置固定底部留白。
- 应用与文件表格共用列宽交互：名称列填满可用空间，数据列支持拖动、最小宽度、双击/Home 复位和左右键微调；应用操作列固定宽度。各表格独立保存本机列宽偏好。表头和正文使用同一组列宽、同步横向位置，纵向滚动条只出现在正文；表头末端按实际滚动条宽度补偿，鼠标拖动无蓝框、键盘焦点仅强调分隔线。
- 右键菜单使用小图标、文字及分组；普通区域阻止 WebView 的 Reload 等默认菜单。移除设备属于可恢复隐藏，不使用危险操作红色。可点击控件使用手型，输入框保留文本光标，禁用状态使用默认光标，分栏使用横向调整光标。
- 焦点样式在应用根部统一管理，覆盖按钮、链接、输入框、复选框、标签、折叠项、设备/文件行及 Teleport 弹窗、菜单；禁止在单个控件继续叠加独立的蓝色光圈。鼠标点击和鼠标触发的自动聚焦均不显示外框；Tab、方向键及键盘激活保留清晰焦点，输入普通文字、组词和系统快捷键不误切换模式。
- 输入框保留单层编辑边框；菜单与下拉选项通过背景高亮提示键盘位置，不给菜单、对话框和标签面板容器画大外框。设备/文件行的键盘焦点内缩，避免被列表边缘裁切；分栏键盘焦点仅显示 1px 中线。保留实际焦点、选中状态和控件原有键盘行为。
- 界面语言支持简体中文和 English，首次按系统首选语言确定并保存，之后手动选择，详见 `docs/i18n.md`。
- 对话框布局统一；标签与输入显式关联，帮助文字与错误就近显示；Esc 关闭并返回触发按钮，任务执行时禁止误关闭。
- 复选框选中态在悬停、按下及键盘焦点时保持强调色背景与清晰勾选标记，不继承通用按钮的浅色悬停背景；禁用时仍可辨认已选与未选。
- 禁用态不能靠透明度掩盖说明。一个区域最多一个主操作；异步过程保留状态和停止等待。
- 动效仅限 100ms 控件颜色反馈与执行中指示；遵循 reduced-motion，不使用入场、弹跳、缩放动画。

## 交付检查

验证默认 1100×740、920×640 最小窗口对应的窄工作区、侧栏最小宽度、长设备名称与长组件、所有标签页、连接与设置对话框、键盘 Tab/方向键/Esc、选中/悬停/禁用和主操作文字对比度。仅支持浅色，不声称已验收深色或移动端。macOS 实测与 Windows 静态/构建检查分别记录。
